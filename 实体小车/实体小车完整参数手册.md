## 3. 运动控制参数

### 3.1 底盘驱动核心参数 (robot_driver.cpp)

| 参数 | 值 | 说明 |
|------|-----|------|
| `prm` | 178 | 速度标定系数 |
| `car_width` | 0.25 m | 轮距 |
| `car_lenght` | 0.24 m | 轴距 |
| `k_r` | 1.0 | 旋转校准系数 |
| `k_x` | 1.0 | 前进校准系数 |
| `k_y` | 1.0 | 横向校准系数 |
| 编码器分辨率 | 660 脉冲/圈 | 四倍频后每圈脉冲数 |
| 里程计发布频率 | 20 Hz | odom话题更新频率 |
| 串口读取频率 | 20 Hz | 底盘数据读取频率 |

### 3.2 最大速度限制（硬件级）

由代码 `x_max = 1.56*prm/330` 等公式计算：

| 速度参数 | 公式 | 计算值 | 单位 |
|----------|------|--------|------|
| 最大前进速度 `x_max` | 1.56 × 178 / 330 | **≈ 0.842** | m/s |
| 最大横向速度 `y_max` | 1.72 × 178 / 330 | **≈ 0.928** | m/s |
| 最大旋转角速度 `w_max` | 5.9 × 178 / 330 | **≈ 3.183** | rad/s |

### 3.3 编码器到速度的换算公式

```cpp
// 编码器原始值 → 物理速度
float angle    = -encoder[0] / 660 * 0.049 * PI * k_r * prm / 330 * 0.49 / (car_width + car_lenght);
float throttle = -encoder[1] / 660 * 0.049 * PI * k_x * prm / 330;
float rampage  =  encoder[2] / 660 * 0.049 * PI * k_y * prm / 330;
```
- `660` = 编码器每圈脉冲数（四倍频后）
- `0.049 * PI` = 车轮周长（m）
- `prm / 330` = 速度标定系数

### 3.4 控制命令映射

上位机发送归一化速度 `[-1.0, 1.0]`，映射为整数 `[1, 254]`：
```python
angle_    = round((car_vel[0] + 1.0) * 126.5 + 1.0)  # → [1, 254]
throttle_ = round((car_vel[1] + 1.0) * 126.5 + 1.0)
rampage_  = round((car_vel[2] + 1.0) * 126.5 + 1.0)
```

### 3.5 速度限幅（ROS cmd_vel回调）

```cpp
serialCmd[0] = inside(-w_max, w_max, data.angular.z);  // 角速度限幅 ±3.183 rad/s
serialCmd[1] = inside(-x_max, x_max, data.linear.x);   // 前进限幅 ±0.842 m/s
serialCmd[2] = inside(-y_max, y_max, data.linear.y);   // 横向限幅 ±0.928 m/s
```

## 9. ROS话题与坐标系

### 9.1 ROS话题列表

| 话题名 | 消息类型 | 方向 | 说明 |
|--------|----------|------|------|
| `/cmd_vel` | `geometry_msgs/Twist` | 输入 | 速度命令（linear.x, linear.y, angular.z） |
| `/odom` | `nav_msgs/Odometry` | 输出 | 里程计位姿（位置+姿态四元数） |
| `/scan` | `sensor_msgs/LaserScan` | 输出 | 激光雷达扫描数据 |
| `/camera/depth_registered/image_raw` | `sensor_msgs/Image` | 输出 | 深度图像（单位mm） |
| `/IMU` | `sensor_msgs/Imu` | 输出 | IMU数据（加速度+角速度+姿态） |
| `/encoder` | `robot_driver/car_vel` | 输出 | 编码器数据（angle, throttle, rampage） |
| `/tf` | `tf2_msgs/TFMessage` | 输出 | 坐标变换 |

### 9.2 坐标系 (TF Tree)

```
map → odom → base_footprint → radar (激光雷达)
                          → camera (深度摄像头)
```

| 坐标系 | 说明 |
|--------|------|
| `map` | 全局固定坐标系（SLAM建图结果） |
| `odom` | 里程计坐标系（连续，无跳变） |
| `base_footprint` | 机器人底盘坐标系（2D投影） |
| `radar` | 激光雷达坐标系 |

### 9.3 里程计更新公式

```cpp
// 里程计位姿积分（20Hz）
posdata[2] += encoder.angle;                                    // yaw累加
posdata[0] += encoder.throttle * cos(posdata[2]) - encoder.rampage * sin(posdata[2]);  // x
posdata[1] += encoder.throttle * sin(posdata[2]) + encoder.rampage * cos(posdata[2]);  // y
```

## 13. 运动学模型总结

### 13.1 麦克纳姆轮全向运动学

小车采用4轮麦克纳姆轮布局，支持三自由度运动：

```
        ↑ x (前进)
        |
  y ←---+---→ (横向)
        |
        ↓

vx = (v_wheel_FL + v_wheel_FR + v_wheel_BL + v_wheel_BR) / 4
vy = (-v_wheel_FL + v_wheel_FR + v_wheel_BL - v_wheel_BR) / 4
ω  = (-v_wheel_FL + v_wheel_FR - v_wheel_BL + v_wheel_BR) / (4 * (l + w))
```

其中 `l` 为半轴距，`w` 为半轮距。

### 13.2 实际运动约束汇总

| 约束类型 | 参数 | 值 |
|----------|------|-----|
| 硬件最大线速度(x) | `x_max` | 0.842 m/s |

| 硬件最大角速度 | `w_max` | 3.183 rad/s |

| DWA最大线速度(y) | `max_vel_y` | 0.1 m/s |

## 14. 多模态传感器数据特征（供轨迹预测参考）

### 14.1 可用模态

| 模态 | 数据源 | 频率 | 数据维度 | 特点 |
|------|--------|------|----------|------|
| **激光雷达** | `/scan` | ~5-10 Hz | 360点/帧 | 2D平面距离，maxRange=5.5m |
| **深度图像** | `/camera/depth_registered/image_raw` | ~30 Hz | 2D深度图(mm) | 3D空间距离，TOF原理 |
| **RGB图像** | 摄像头 | ~30 Hz | 2D彩色图 | 超广角，路面信息 |
| **里程计** | `/odom` | 20 Hz | (x, y, θ) | 编码器积分，存在累积误差 |
| **IMU** | `/IMU` | 20 Hz | (acc_xyz, gyro_xyz) | 6轴惯性测量 |
| **编码器** | `/encoder` | 20 Hz | (angle, vel_x, vel_y) | 原始轮速数据 |

### 14.2 传感器融合特点

- 激光雷达 + 里程计：用于SLAM建图(Gmapping)和定位(AMCL)
- 激光雷达 + 里程计：用于laser_scan_matcher位置校准
- 深度摄像头 + 激光雷达：互补感知，深度相机填补激光雷达近距离盲区
- RGB摄像头：CNN自动驾驶模型输入
- IMU + 编码器：里程计姿态解算

### 14.3 低速场景特征

基于实际DWA配置，该小车的实际运行速度极低：
- 导航前进速度：0.015 ~ 0.12 m/s（约0.05~0.43 km/h）
- 导航角速度：0.2 ~ 0.5 rad/s
- 属于典型低速室内场景
- 运动空间：4.5m × 3m 室内环境
- 障碍物：锥桶、围挡等静态障碍物

## 15. 轨迹预测系统改写建议要点

1. **运动学约束**：使用麦克纳姆轮全向运动学模型，三自由度(vx, vy, ω)，而非差速模型
2. **速度范围**：实际导航速度极低（vx∈[-0.03, 0.11], vy∈[-0.1, 0.1], ω∈[0.2, 0.5]），加速度上限3.0
3. **多模态输入**：可融合激光雷达(2D点)、深度图像(3D点)、RGB图像、里程计、IMU、编码器六种模态
4. **时间分辨率**：控制频率20Hz，里程计20Hz，传感器5-30Hz，建议预测时间窗口2s（与DWA sim_time一致）
5. **空间尺度**：室内环境，地图范围±5m，栅格5cm，赛道4.2m×4.06m
6. **目标精度**：位置容差8cm，航向容差8.6°
7. **轻量化需求**：上位机为Intel NUC，算力有限，模型需轻量化
8. **坐标系**：map(全局) → odom(里程计) → base_footprint(机器人)，轨迹预测在odom或map坐标系下进行
